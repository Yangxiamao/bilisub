使用前请阅读

  • 会产生 Gemini API 费用，从你的 Google 账户扣除。按测试视频实测，每小时音频大约：。只转写播放位置前方的一段（默认 2 分钟），不会一次转写整部视频。
  • 音频片段会发送给 Google（Gemini API）进行识别。扩展请求时设置了 store:false。付费项目的数据不会用于训练模型，但 Google 仍可能为防止滥用短期保留日志；免费层项目的数据可能被用于改进 Google 产品。详见 Gemini API 附加服务条款。
  • API Key 只保存在本机浏览器（chrome.storage.local），只会发送给 generativelanguage.googleapis.com。

基本设置

保持"当前位置 → 当前位置 + 预读时长"已转写。越长越不容易等待，但拖动进度条后被丢弃的转写也越多。
